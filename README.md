# Whirled Club Client for Linux

Unofficial Electron shell for the Ruffle version of Whirled Club. Not affiliated with Whirled Club.

## Install

Download the bundle from the releases page, then:

    flatpak install --user wcruffle-1.0.0-1.flatpak
    flatpak run io.github.Veeiss.wcclient_linux.wcruffle

## Build

    flatpak install --user flathub org.freedesktop.Platform//25.08 org.freedesktop.Sdk//25.08 org.electronjs.Electron2.BaseApp//25.08
    ./build.sh

The stylesheet, icons and app icon are Whirled Club's, used with permission.
